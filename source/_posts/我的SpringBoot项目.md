## 编码语言
> 该项目是后台项目 主要使用的编程语言是 SpringBoot, 以及MybatisPlus+MySql开发 
---


## 项目介绍
---
使用 `Springboot` 开发的后端,采用`MybatisPlus`框架实现后端部分sql自动生成，Mysql编写触发器等
>技术栈: Springboot、Mysql、postman、MybatisPlus

>职责描述:
1.使用SpringBoot完成后端，使用JWT实现以及自定义注解拦截器实现登录Token验证用户信息
2.使用MybatisPlus对简单的sql处理节省编写sql时间
3.使用mysql触发器对一些需要联动修改的实体类进行联动
4.编写sql语句，对复杂的多表进行联合查找，返回接口信息
## 初始化
---
```
git clone https://github.com/UnfunLady/reactApp_backend.git ./backend
打开项目等待依赖环境下载完毕 运行springboot项目 注意：先修改mybatisplus的配置
修改数据库名 端口号等与你的环境一致即可
```

## 运行环境(参考)
>Mysql-version:**8.0+**、springboot
## 运行步骤
```bash
1.一般使用 `IDE编辑器` 打开后台项目
2.运行Navicat 或者 sqlyog等工具方便对数据表进行导入
2.运行项目 等待后端项目启动
```
